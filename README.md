# 🔑  Password Generator

A secure, random password generator built completely in Python to help you create strong, unhackable passwords.

## 🚀 Features

*   **Custom Length**: Specify exactly how many characters you want.
*   **Strong Entropy**: Includes uppercase, lowercase, numbers, and special symbols.
*   **Secure Generation**: Uses Python's secure modules for randomness.
*   **Command Line Interface**: Fast, light, and easy to run.

## 🛠️ Built With

*   Python 3

## 💻 Getting Started

### Prerequisites

Make sure you have Python 3 installed on your computer. You can check by running:
```bash
python --version
```

### How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the folder:
   ```bash
   cd password_generator
   ```
3. Run the script:
   ```bash
   python generator.py
   ```
